# -# 随身记账 · 移动记账本

一款纯前端实现的移动端记账 Web App，数据保存在浏览器本地，无需后端服务器。

## 功能特性

- **记一笔**：快速记录支出/收入，支持多级分类、日期、备注
- **预算与攒钱目标**：设置月度/年度预算，支持多个攒钱目标，预算超支提醒
- **分类占比**：线性条形图 / 环形图两种展示方式，支持本月/本年/全部时间范围
- **周期报告**：日报/周报/月报/年报，支持自定义对照区间，口语化建议
- **外观定制**：跟随系统深浅色 / 白天 / 夜间 / 护眼四种模式，15 种中国传统色色卡可选
- **数据管理**：导出/导入 JSON 备份，示例数据一键填充，支持注销账户

## 部署到 GitHub Pages

### 步骤

1. 登录 [GitHub](https://github.com)，点击右上角 **+** → **New repository**
2. 仓库名填写 `你的用户名.github.io`（例如 `zhangsan.github.io`），设为 **Public**
3. 上传本仓库中的 `index.html` 和 `README.md` 两个文件到仓库根目录
4. 进入仓库 **Settings** → **Pages** → **Source** 选 `main` 分支 → **Save**
5. 等待 1~2 分钟后，通过 `https://你的用户名.github.io` 访问

### iPhone Safari 使用

部署成功后，在 Safari 中打开你的网页：
1. 点击底部中间的 **分享按钮**（方框+箭头图标）
2. 向下滑动找到并点击 **"添加到主屏幕"**
3. 命名后点击"添加"

这样你的 iPhone 主屏幕上就会出现一个图标，点击直接打开记账应用，体验和原生 App 几乎一样。

## 技术说明

- 纯 HTML + CSS + JavaScript 单文件实现，无任何外部依赖
- 数据存储在浏览器 `localStorage` 中，不上传任何服务器
- 兼容现代浏览器，针对移动端做了响应式优化
- 支持 PWA 添加到主屏幕（`apple-mobile-web-app-capable` meta 已配置）
